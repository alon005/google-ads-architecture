# The Locksmith Connections websites

**The paid-ads landing pages and the organic site, built and run since 2013.**

*Showcase page. The code is private; a walkthrough is available on request.*

---

## What they are

- **The PPC site:** landing pages for Google Ads, one per market and service, built to turn a click into a call.
- **The organic site:** the brand's site and its town pages, built to be found on search.

## The story

- **On WordPress for years:** I developed and ran both sites myself and kept improving them.
- **Conversion tracking by hand:** I built the conversion tracking and implemented it myself across the landing pages, so every ad click and call could be measured.
- **Rebuilt in 2026:** both sites rebuilt on Cloudflare with AI coding agents, with the tracking built in.

**Stack:** WordPress (until 2026) · Cloudflare · Google Ads conversion tracking
